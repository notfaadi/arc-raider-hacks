Cloudflare → Settings → Builds → Deploy command (replace npx wrangler deploy):

node scripts/cf-deploy-step.mjs

Build command stays: npm run build
Build output directory: dist

If you use Retry on an old failed deployment, Cloudflare keeps an OLD commit
(without these scripts). Use: Deployments → Create deployment → main → latest.

GitHub Actions (recommended): add secrets CLOUDFLARE_API_TOKEN and
CLOUDFLARE_ACCOUNT_ID — push to main deploys automatically (.github/workflows/cloudflare-pages.yml).
